```python3
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode()
        dummy.next = head

        ptr = dummy

        while ptr.next is not None and ptr.next.next is not None:
            if ptr.next.val == ptr.next.next.val:
                copy = ptr.next
                while copy.next is not None and copy.val == copy.next.val:
                    copy = copy.next
                
                ptr.next = copy.next
            else:
                ptr = ptr.next
        
        return dummy.next
```

飛ばしたノードのメモリの解放についてコメントされているコードがあった。
その人はC++のコードだったが、自分はPythonで書いており、メモリの解放の仕方を知らなかったので調査した。
ガベージコレクションという機能で参照されていないオブジェクトのメモリを解放してくれるらしい。
Pythonでは参照カウント方式という方法を用いているらしい。今何か所から参照されているかカウントしておく。カウントが0になったらそのメモリを解放するらしい。
循環して参照しあってるものには参照カウント方式が使えないので、参照カウントとは別の、循環を検知するアルゴリズムで外部から参照できない循環を見つけるらしい。
循環を見つける具体的な仕組みはドキュメントを探したが見つからなかった。知らなくても問題ないことなのかもしれない。とりあえずchatgptに聞いた。

まず、オブジェクトには作成された時期によって世代に分けられる。
循環がないかは世代ごとに判定を行う。
各オブジェクトの参照カウントをgc_refsという変数に記録する。
gc_refsから同世代のオブジェクトから参照されている数を引く。
引いた結果gc_refs>0なら違う世代から参照されていることになる。
そのため循環がないだろうと考えられる。
gc_refs = 0のオブジェクトに関しては同世代のgc_refs>0のオブジェクトからたどれるか調査する。辿れたらreachable、辿れなかったらunreachable。
unreachableは循環していると考えられるので、メモリを解放する。

らしい。
Pythonはメモリ解放を基本的に勝手にやってくれることが分かった。

```python3
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if head is None:
            return None
        
        dummy = ListNode()
        dummy.next = head
        ptr = dummy

        while ptr.next is not None and ptr.next.next is not None:
            if ptr.next.val != ptr.next.next.val:
                ptr = ptr.next
            else:
                duplicated_val = ptr.next.val
                runner = ptr.next
                while runner.next is not None and runner.next.val == duplicated_val:
                    runner = runner.next
                
                ptr.next = runner.next
        
        return dummy.next
```
