step1
今確認しているノードのと違う値のノードが出てくるまで、次のノードを削除する。というのを繰り返せばよいのではと思った。
実際にテストケースを頭で動かしたときに、ノードを消した際に行き止まりだった時に判定ができなくなったので、if文でもし行き止まりだったらbreakとした。
とりあえず実行はできた。

```python3
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if head is None:
            return None
        
        curr = head

        while curr is not None and curr.next is not None:
            while curr.val == curr.next.val:
                curr.next = curr.next.next
                if curr.next is None:
                    break
                    
            curr = curr.next
        
        return head
```

# Definition for singly-linked list.
# class ListNode:

#         self.val = val
#         self.next = next
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if head is None:
            return None
            
        node = head

        while node.next is not None:
            if node.val == node.next.val:
                node.next = node.next.next
            else:
                node = node.next
        
        return head
